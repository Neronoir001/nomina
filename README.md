# Nomina

Application privée de fiches de personnages pour un groupe d'amis (jeu de rôle).

Ce dépôt ne contient **que le moteur de l'application**, sans aucun contenu de jeu : les données sont transmises
localement entre les appareils des joueurs.

- Application web installable (PWA), fonctionne hors ligne.
- Synchronisation pair-à-pair entre appareils (WebRTC).

Version actuelle : prototype de synchronisation.
